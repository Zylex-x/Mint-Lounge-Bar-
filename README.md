# Le Mint — Bar lounge

Site vitrine informatif du Mint à Remiremont.

## Stack
- HTML, CSS et JavaScript vanilla
- Three.js pour l'objet 3D du hero
- Galerie photo avec lightbox

## Développement local
Ouvrir `index.html` avec un serveur local. Le projet charge Three.js et les polices depuis des CDN.

## Publication
Dans GitHub → Settings → Pages, choisir `Deploy from a branch`, puis `main` et `/ (root)`.

## Note de conformité
Le site est volontairement limité à des informations neutres sur l'établissement et les horaires. Il ne présente pas les produits du tabac, les saveurs, les tarifs, les promotions ni d'incitation à leur consommation. Faire vérifier la conformité juridique finale avant mise en ligne.
