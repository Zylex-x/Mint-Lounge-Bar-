# Le Mint — Bar lounge

Site d'informations pratiques du Mint à Remiremont, construit en HTML, CSS et JavaScript.

## Fonctionnalités
- Direction visuelle sombre, avec détails bronze et vert végétal.
- Objet abstrait 3D animé avec Three.js.
- Navigation responsive.
- Galerie photo avec agrandissement (lightbox).
- Horaires hebdomadaires et copie des horaires.
- Effets d'inclinaison 3D légers sur les cartes et boutons.

## Lancer localement
Ouvrir le dépôt avec un serveur local (par exemple Live Server dans VS Code). Three.js et les polices sont chargés depuis des CDN.

## Publier avec GitHub Pages
Dans Settings → Pages, choisir « Deploy from a branch », puis la branche `main` et le dossier `/ (root)`.

## Données à confirmer
L'adresse exacte, le téléphone et les profils sociaux n'ont pas été vérifiés auprès du nouvel établissement et ne sont donc pas affichés. Les horaires sont ceux transmis par l'utilisateur.

## Note de conformité
Le site reste volontairement neutre : pas de produits du tabac, parfums, tarifs, promotions, visuels de chicha ou appel à consommer. Le Code de la santé publique interdit la publicité directe et indirecte en faveur du tabac (articles L.3512-4 et L.3512-5). Une validation juridique de la version finale est recommandée avant publication.
